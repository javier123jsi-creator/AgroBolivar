AgroBolívar

Descripción

AgroBolívar es una plataforma web desarrollada como prototipo académico para promover y facilitar la comercialización de productos agrícolas de pequeños productores del municipio de Bolívar, Cauca.

La plataforma permite registrar productores, publicar productos agrícolas, consultar un catálogo, buscar productos y establecer contacto entre compradores y productores mediante mensajes.

Tecnologías utilizadas

PHP

MySQL

HTML5

CSS3

JavaScript

XAMPP

Visual Studio Code

Requisitos para ejecutar el proyecto

Tener instalado XAMPP.

Tener instalado un navegador web.

Contar con los archivos del proyecto y la base de datos agrobolivar.sql.

Instalación y ejecución

Instalar y abrir XAMPP.

Iniciar los servicios Apache y MySQL.

Copiar la carpeta plataforma_agricola dentro de la carpeta htdocs de XAMPP.

Abrir phpMyAdmin desde http://localhost/phpmyadmin.

Crear una base de datos llamada agrobolivar

Seleccionar la base de datos e importar el archivo agrobolivar.sql.

Verificar la configuración de conexión en config/conexion.php.

Abrir el navegador e ingresar a:

http://localhost/plataforma_agricola/

Consideraciones

Este proyecto corresponde a un prototipo funcional desarrollado en un entorno local con fines académicos. No incluye pagos electrónicos, gestión de pedidos ni servicios de transporte.
